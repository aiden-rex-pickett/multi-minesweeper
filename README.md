# Multiplayer Minesweeper

I just want to do something with zig, and this seemed like a good project for it. 

### Game Idea

The idea is to make a multiplayer minesweeper game where many many players can play on the
same board, and you get points based on the "value" of the cells that you uncover. So something
like a 0 might be worth 1 point, 1 is 2 points, etc and 8 is 1000 or something like that. So
there is only a finite number of points availble, so the game is zero sum and players have to rush to
get the largest sum of points they can before the board is completely cleared out.

And of course you instantly loose if you hit a mine.
